# Fuente de las imágenes

Las imágenes de posición inicial y final proceden de **Free Exercise DB**, un dataset abierto y
publicado como dominio público:

- https://github.com/yuhonas/free-exercise-db

Se guardan localmente para evitar dependencias externas durante la navegación del catálogo.

Las dos imágenes de `flexion-mancuernas-agarre-neutro` fueron generadas específicamente para este
catálogo con la herramienta integrada de generación de imágenes de OpenAI, manteniendo la misma
persona, entorno y ángulo entre las posiciones inicial y final.
