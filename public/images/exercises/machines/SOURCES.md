# Fuente de las imágenes

Las imágenes de posición inicial y final de las máquinas proceden de **Free Exercise DB**, un
dataset abierto publicado como dominio público:

- https://github.com/yuhonas/free-exercise-db

Cada par muestra a una persona ejecutando el movimiento. Se guarda localmente para mantener el
catálogo disponible sin conexiones externas.
